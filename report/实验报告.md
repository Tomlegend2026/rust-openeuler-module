## 一 实验目的

本实验通过编写 Rust 内核模块，理解用户态与内核态的区别、可加载模块生命周期以及 Rust 所有权和资源清理机制。实验要求在 openEuler 中构建模块，并在系统运行期间动态加载和卸载，形成可复现操作记录。

## 二 实验方案

模块命名为 rust_team2。加载时创建并保存六个整数 `[3,1,4,1,5,9]`，计算元素数、总和、最小值、最大值、整数平均值和极差，输出内核日志。卸载时输出模块仍持有的数据概况，然后通过 Rust 的字段析构释放向量分配。模块没有用户输入接口、设备节点、后台线程或定时器，使验证重点集中于初始化、错误传播与资源生命周期。

算法预期结果为元素数6、总和23、最小值1、最大值9。空输入与溢出是独立的错误路径；默认模块数据不会触发它们，使用主机侧测试验证算法对这些情况的处理。

## 三 环境与源码基线

源码选定 openEuler GitHub 镜像 openEuler-24.03_LTS 分支中的提交 `6e0c18da64fd9919a51f8f2216a371503a5e2763`。已核对该提交的最小 Rust 示例、Module trait、工具版本脚本与 Kconfig，确认其使用 Rust 1.73.0、bindgen 0.65.1、Vec::try_push 和单参数 init 入口。

源码接口核对与实际运行分别记录。实际环境为x86_64 openEuler 24.03 LTS、内核6.6.0-team2-rust+、Rust 1.73.0、LLVM 17.0.6、bindgen 0.65.1，完整配置和版本见environment/版本记录.md。内核已启用Rust、模块支持与模块卸载。完整搭建步骤见environment/搭建步骤.md。

## 四 关键实现

### 4.1 模块初始化

module! 宏登记类型和模块信息。init 创建 Vec，并用 try_push 逐个加入数字。分配失败时，问号操作符将错误返回内核，局部向量依所有权规则析构；初始化成功时，向量与统计结果一起移动进 RustTeam2 实例。

### 4.2 统计函数

summarize 的参数为只读切片，数据所有权保留在调用方。函数先拒绝空输入，再扫描数据计算结果。累加使用 checked_add，溢出返回 SumOverflow；内核入口将统计错误转换为 EINVAL。独立计算文件可以在不加载内核的情况下测试，但这些测试不覆盖内核分配器或装卸机制。

### 4.3 状态保存和卸载

模块在加载期间持有 values 与 summary。卸载时先执行 Drop，输出 unload_begin 日志，随后自动析构字段，Vec 释放其缓冲区。日志发生于字段释放之前，因此只能作为清理路径被进入的证据。还需结合卸载命令成功、模块列表变化和异常日志检查评价实验结果。

### 4.4 内核构建

内核模块通过 Kbuild 编译，生成 rust_team2.ko，使用目标内核的配置和 Rust 构建产物；主机侧 rustc 只用于验证可独立测试的统计逻辑。构建脚本先检查固定环境再编译，保存错误信息、模块信息及校验值，便于追踪所测试代码。

## 五 实验步骤与预期现象

1. 按搭建说明安装工具链，完整构建并启动实验内核，确认 uname 与 kernelrelease 相同。
2. 在仓库运行环境检查和构建脚本，确认生成 .ko，查看 modinfo。
3. 使用 insmod 加载，通过 lsmod 和内核日志观察结果。
4. 使用 rmmod 卸载，再检查模块列表和清理日志。
5. 运行10轮循环脚本，保存逐轮结果与本次新增日志。
6. 在无并发操作的实验环境中验证重复加载与卸载不存在模块的预期失败。

预期日志片段如下，仅用于核对：

```text

[rust_team2] event=stats_detail average=3 range=8
[rust_team2] event=unload_begin retained=6 sum=23
```

## 七 问题与限制

实测中修正了 Rust 构建产物文件名检查、模块内部可见性不符合 unreachable-pub 检查、sudo 日志目录归属三项问题。实际操作记录见 environment/2026-10-06实际搭建记录.md。日志出现树外模块 taint 提示，没有匹配到 BUG、Oops、WARNING 或 kernel panic；此结论限于本次有限装卸测试。Rust 内核 API 会随内核版本变化，因此整个小组使用相同源码提交与工具链。

实现使用安全 Rust 表达业务逻辑，并不意味着整个执行环境没有 unsafe 或系统缺陷。参考示例、代码来源和许可在 THIRD_PARTY_NOTICES.md 中说明。
