# 下载链接与安装位置

更新及链接核对日期：2026-10-19。

本仓库不上传现成虚拟机，也没有本组虚拟机的网盘下载链接。以下是从零搭建所需的官方软件、系统镜像和源码入口。下载 openEuler ISO 只是取得操作系统安装盘，还需要安装系统、配置工具链、构建并启动 Rust 实验内核。

## 1 在 Windows 电脑上下载什么

以下链接在你自己的 Windows 浏览器中打开。

| 下载内容 | 具体链接 | 用途与注意事项 |
|---|---|---|
| VMware Workstation Pro | [官方软件下载入口](https://support.broadcom.com/group/ecx/productdownloads?freeDownloads=true&subfamily=VMware+Workstation+Pro) | 选择适用于 Windows 的安装程序，在 Windows 上安装。官方入口要求注册或登录 Broadcom 账号。已有可用版本可继续使用。 |
| VMware 下载步骤 | [Broadcom 官方下载与许可说明](https://knowledge.broadcom.com/external/article/368667/download-and-license-vmware-desktop-hyper.html) | 如果上面的入口跳转到登录页，登录后按说明进入 Workstation Pro 的下载列表。 |
| openEuler 安装镜像 | [openEuler-24.03-LTS-x86_64-dvd.iso，约 3.9 GiB](https://repo.openeuler.org/openEuler-24.03-LTS/ISO/x86_64/openEuler-24.03-LTS-x86_64-dvd.iso) | 下载到 Windows 的普通文件夹，再在 VMware 新建虚拟机时选择这个 ISO。它不是已装好的虚拟机。 |
| 镜像 SHA256 文件 | [对应的 .iso.sha256sum](https://repo.openeuler.org/openEuler-24.03-LTS/ISO/x86_64/openEuler-24.03-LTS-x86_64-dvd.iso.sha256sum) | 用于确认 ISO 下载完整且与官方文件一致。 |
| 镜像备用入口 | [openEuler 官方镜像目录](https://repo.openeuler.org/openEuler-24.03-LTS/ISO/x86_64/) | 直链无法打开时从目录选择同名 ISO，避免误选 everything、debug 或 netinst 版本。 |
| Git for Windows（可选） | [Git 官方 Windows 下载页](https://git-scm.com/install/windows) | 仅用于在 Windows 管理代码；不是运行内核实验的必需安装项。 |

本实验已实测的镜像是 **openEuler 24.03 LTS、x86_64、标准 DVD 版**。ARM 电脑不能据此直接认定本组的 x86_64 虚拟化方案适用，应另行核对虚拟化和架构支持。

镜像对应的 SHA256（已与官方校验文件核对）：

```text
786b9683659512e71c978c34aea806a97ed6cacf04e1b0a22017a50eec582cbe
```

**以下命令只在 Windows PowerShell 执行**。先将示例路径换成你实际保存的 ISO 路径，再运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'D:\Downloads\openEuler-24.03-LTS-x86_64-dvd.iso'
```

比较输出中的 Hash 与上面的值，字母大小写不影响比较。不要把示例路径当成本机已经存在的文件。

## 2 安装虚拟机系统

在 Windows 打开 VMware，新建虚拟机并选择下载的 ISO，按照安装向导完成 openEuler 安装。自行创建普通用户并记录自己的登录密码，不要使用或索要其他组员的个人密码。

本组实测配置为 4 vCPU、6 GiB 内存、60 GiB 虚拟磁盘，使用裁剪过的实验内核配置；若完整编译发行版驱动集合，需要更多资源。它是实测记录，不保证所有主机上具有相同的编译耗时或磁盘占用。

系统安装完成后，进入 **VMware 里面的 openEuler 终端**。后续工具链安装、编译内核和模块装卸都在这里执行。不要在 Windows PowerShell 中执行 `dnf`、`insmod` 或 `rmmod`。

## 3 在 openEuler 虚拟机中获取工具链和源码

| 内容 | 官方入口 / 固定版本 | 在哪里使用 |
|---|---|---|
| Rust 安装工具 rustup | [Rust 官方安装入口](https://rustup.rs/) | 在 openEuler 终端安装 Linux 工具链。本项目选择 Rust **1.73.0**，不是 Windows 的 rustup-init.exe。 |
| Rust 1.73.0 与组件 | `rustup toolchain install 1.73.0 --profile minimal --component rust-src --component rustfmt` | openEuler 终端；先完成 rustup 安装，详见搭建步骤。 |
| bindgen-cli 0.65.1 | [官方包注册表对应版本](https://crates.io/crates/bindgen-cli/0.65.1) | openEuler 终端，通过 `cargo install --locked --version 0.65.1 bindgen-cli` 安装。 |
| LLVM / Clang 17.0.6 | [LLVM 官方 17.0.6 发布页](https://github.com/llvm/llvm-project/releases/tag/llvmorg-17.0.6) | 实测版本参考。在 openEuler 中按搭建步骤通过 dnf 安装依赖并核对版本；这个发布页不是必须另装一套工具链的要求，不要下载 Windows 安装程序用于虚拟机。 |
| openEuler 内核源码 | [源码仓库](https://github.com/openeuler-mirror/kernel)、[固定提交](https://github.com/openeuler-mirror/kernel/commit/6e0c18da64fd9919a51f8f2216a371503a5e2763) | 在 openEuler 的 `$HOME/os-lab/kernel` 获取和构建，固定提交与 [baseline.env](baseline.env) 一致。 |

表中的工具版本是本组实测基线。完整依赖安装、内核配置及启动流程以 [搭建步骤](搭建步骤.md) 为准，不要只装 Rust 就直接尝试加载模块。

## 4 获取本组代码并继续复现

首次获取项目时，**在 openEuler 终端**执行以下命令。需要先按照搭建步骤安装 Git。已有项目目录时先检查，不要覆盖已有代码或重复克隆到同一目录。

```bash
mkdir -p "$HOME/os-lab"
cd "$HOME/os-lab"
git clone --branch codex/rust-module-delivery-20261018 https://github.com/Tomlegend2026/rust-openeuler-module.git
cd rust-openeuler-module
pwd
```

路径中的用户名由你自己的账号决定。账号叫 `team2` 时是 `/home/team2/os-lab/rust-openeuler-module`，其他账号不必改名为 team2。

推荐顺序：

1. 按 [环境搭建步骤](搭建步骤.md) 完成依赖安装、固定内核源码获取、Rust 配置、内核构建和启动。
2. 在 openEuler 终端确认 `uname -r` 与构建目录的内核版本一致。本组目标版本是 `6.6.0-team2-rust+`。
3. 按 [模块编译、装卸与排障流程](../docs/03-环境与复现流程.md) 重新构建本组模块，执行装卸测试。
4. 保存自己本次操作的版本、日志和截图，不把仓库中的历史日志当作自己的独立复现结果。

只做 Rust 学习、源码讲解或报告审核的组员，可以先从 [从零开始](../docs/00-从零开始.md) 和 [Rust 基础讲义](../learning/Rust基础与练习.md) 入手，不必每个人都重新编译整个内核。
