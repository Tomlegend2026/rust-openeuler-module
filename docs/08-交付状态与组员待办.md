## 再次复现装卸的命令（本日已执行通过）

在VM终端登录team2执行，密码只在VM内输入：

```sh
cd ~/os-lab/rust-openeuler-module
sudo bash -c 'bash scripts/test-lifecycle.sh module/rust_team2.ko 10 && bash scripts/test-negative.sh module/rust_team2.ko'
```

会分别生成新的lifecycle与negative证据目录。负向脚本应证明重复加载返回非零、已有模块仍存在；正常卸载后再次卸载返回非零，模块仍不存在。不得删除失败输出或使用强制卸载。重新装卸不是补造历史证据，运行日期按新日志记录。
